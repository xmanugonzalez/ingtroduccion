1. CREATE TABLE y tipos de datos

Una base de datos relacional organiza la información en tablas (filas y columnas). Para crear una tabla en SQL Server se usa CREATE TABLE, indicando el nombre de cada columna y su tipo de dato:

CREATE TABLE productos (
    id INT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    precio DECIMAL(12,2),
    stock INT
);

Tipos de datos más usados en SQL Server:

  • INT: números enteros (también BIGINT, SMALLINT).
  • DECIMAL(p,s): números con decimales exactos, con p dígitos en total y s decimales. FLOAT para decimales aproximados.
  • VARCHAR(n): texto de hasta n caracteres. NVARCHAR(n) es lo mismo pero admite cualquier alfabeto (Unicode).
  • DATE y DATETIME: fechas y fechas con hora.
  • BIT: valores 0 / 1, el equivalente a un booleano.

Restricciones que se pueden agregar a una columna:

  • PRIMARY KEY: identifica de forma única cada fila.
  • NOT NULL: obliga a que la columna siempre tenga un valor.
  • IDENTITY(1,1): SQL Server genera el número solo, de a uno.

Ojo con los tipos de otros motores: en SQL Server no existe TEXT como tipo recomendado (se usa VARCHAR(n)) ni AUTOINCREMENT (se usa IDENTITY(1,1)).
