2. INSERT — cargar datos

Se cargan filas con INSERT INTO. Los textos van siempre entre comillas simples:

INSERT INTO productos (id, nombre, categoria, precio, stock)
VALUES (13, 'Mousepad XL', 'Perifericos', 45000, 30);

Se pueden insertar varias filas en una sola sentencia separando los grupos de valores con comas:

INSERT INTO productos (id, nombre, categoria, precio, stock) VALUES
(14, 'Cable HDMI 2m', 'Accesorios', 35000, 50),
(15, 'Hub USB 4 puertos', 'Accesorios', 78000, 20);

Si se omiten columnas, esas quedan en NULL (o con su valor por defecto). Conviene listar siempre las columnas explícitamente, para que la sentencia no dependa del orden físico de la tabla.

Si un texto lleva un apóstrofo, se duplica la comilla: 'Cable 3'' metros'.
