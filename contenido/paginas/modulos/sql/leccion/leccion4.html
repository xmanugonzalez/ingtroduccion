4. UPDATE y DELETE

UPDATE modifica filas existentes. Siempre conviene usar WHERE, salvo que realmente se quiera modificar todas las filas:

UPDATE productos SET stock = stock - 1 WHERE id = 1;

Se pueden actualizar varias columnas a la vez separándolas con comas:

UPDATE productos SET precio = 99000, stock = 12 WHERE id = 2;

DELETE borra filas completas. También necesita WHERE para no vaciar la tabla por accidente:

DELETE FROM productos WHERE id = 7;

Regla de oro: antes de correr un UPDATE o DELETE, probá el mismo WHERE con un SELECT para confirmar qué filas se van a ver afectadas. SQL Server te informa cuántas filas cambiaron.
