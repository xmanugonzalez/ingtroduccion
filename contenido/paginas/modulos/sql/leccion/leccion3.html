3. SELECT y WHERE

SELECT es la sentencia más usada: sirve para leer datos.

SELECT nombre, precio FROM productos;

Para traer todas las columnas se usa *:

SELECT * FROM productos;

Para filtrar filas se agrega WHERE con una condición:

SELECT * FROM productos WHERE precio > 300000;

Operadores útiles en WHERE:

  • =, <> (distinto), >, <, >=, <=
  • AND, OR, NOT
  • LIKE 'Teclado%': empieza con "Teclado" (% es cualquier cantidad de caracteres, _ es exactamente uno).
  • IN ('Audio', 'Monitores'): está en la lista.
  • IS NULL / IS NOT NULL: la columna no tiene valor.

Recordá: los textos van entre comillas simples (WHERE categoria = 'Audio'), nunca dobles.
