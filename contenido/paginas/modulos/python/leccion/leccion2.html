Entrada, salida y operadores

La función print() muestra información en pantalla. La función input() lee lo que escribe el usuario (siempre como texto/str).

nombre = input("¿Cómo te llamás? ")
print("Hola,", nombre)

Python soporta los operadores aritméticos habituales: + - * /, además de // (división entera), % (resto/módulo) y ** (potencia).

print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 5)   # 32

También existen los operadores de comparación (== != < > <= >=) que devuelven True o False.
