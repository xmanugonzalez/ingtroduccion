Bucles: for y while

El bucle for recorre una secuencia (por ejemplo, un range):

for i in range(5):
    print(i)   # imprime 0 1 2 3 4

El bucle while repite mientras una condición sea verdadera:

contador = 0
while contador < 3:
    print(contador)
    contador += 1

range(inicio, fin, paso) permite controlar el rango recorrido. Cuidado con los bucles infinitos: siempre asegurate de que la condición eventualmente sea falsa.
