Condicionales: if / elif / else

Las estructuras condicionales permiten ejecutar código según se cumpla o no una condición. Python usa indentación (4 espacios) en vez de llaves para delimitar bloques.

edad = 18
if edad >= 18:
    print("Sos mayor de edad")
elif edad >= 13:
    print("Sos adolescente")
else:
    print("Sos menor")

Se pueden combinar condiciones con and, or y not.

if edad >= 18 and edad < 65:
    print("Adulto")
