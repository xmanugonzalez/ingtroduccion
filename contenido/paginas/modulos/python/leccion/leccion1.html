Variables y tipos de datos

En Python, una variable es un nombre que apunta a un valor guardado en memoria. No hace falta declarar el tipo: Python lo infiere automáticamente.

nombre = "Ada"      # str (texto)
edad = 30           # int (entero)
altura = 1.65        # float (decimal)
es_estudiante = True # bool (verdadero/falso)

Podés ver el tipo de una variable con la función type():

print(type(edad))   # <class 'int'>

Python es de tipado dinámico: una misma variable puede cambiar de tipo durante la ejecución (aunque no es buena práctica abusar de esto).

Para convertir entre tipos se usan las funciones int(), float(), str(), bool():

edad_texto = "30"
edad_numero = int(edad_texto)  # ahora es un int, se puede sumar

Python es uno de los lenguajes de programación más usados del mundo: se usa para desarrollo web, ciencia de datos, automatización de tareas, inteligencia artificial y mucho más. Es un buen primer lenguaje porque su sintaxis es simple y se lee casi como texto en inglés.
