Funciones y listas

Una función agrupa código reutilizable. Se define con def:

def saludar(nombre):
    return "Hola, " + nombre

print(saludar("Mundo"))

Las listas son colecciones ordenadas y modificables:

numeros = [1, 2, 3]
numeros.append(4)
print(numeros)        # [1, 2, 3, 4]
print(len(numeros))   # 4
print(numeros[0])     # 1 (primer elemento)

Se puede recorrer una lista con for:

for n in numeros:
    print(n)
