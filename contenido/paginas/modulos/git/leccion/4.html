Lección 4: Ramas: git branch, checkout y switch

Una rama (branch) es una línea de desarrollo independiente dentro del mismo repositorio. Te permite probar cosas nuevas o desarrollar una funcionalidad sin afectar la rama principal (normalmente main) hasta que esté lista.

Para crear una rama nueva a partir de la rama actual:

git branch feature

Para ver todas las ramas del repositorio (la actual aparece marcada con *):

git branch

Para moverte a otra rama existente podés usar el comando moderno git switch, o el más clásico git checkout:

git switch feature
git checkout feature

También podés crear y moverte a una rama nueva en un solo paso con git switch -c nombre o git checkout -b nombre.
