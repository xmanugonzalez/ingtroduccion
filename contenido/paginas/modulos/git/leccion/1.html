Lección 1: Qué es el control de versiones y git init

Un sistema de control de versiones lleva un registro de los cambios que hacés a un conjunto de archivos a lo largo del tiempo, para que puedas volver atrás, comparar versiones o trabajar en equipo sin pisarte con otras personas. Git es el sistema de control de versiones más usado del mundo.

Un repositorio (repo) es una carpeta donde Git guarda el historial de cambios, dentro de una subcarpeta oculta llamada .git. Para convertir una carpeta común en un repositorio Git, se usa:

git init

Esto crea el repositorio vacío, sin ningún commit todavía, parado en una rama por defecto (normalmente llamada main). A partir de ahí, el comando git status te permite ver en todo momento en qué rama estás y qué cambios hay pendientes de guardar.

git status

A partir de acá, cada ejercicio te va a mostrar una consola donde podés escribir comandos git con su sintaxis real (la misma que usarías en tu computadora o en cualquier proyecto de verdad) y ver el resultado al instante.
