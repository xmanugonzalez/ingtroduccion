Lección 5: Merge básico

Cuando terminás de trabajar en una rama (por ejemplo feature) y querés incorporar esos cambios a otra rama (por ejemplo main), usás git merge.

El flujo típico es: pararte en la rama que va a recibir los cambios, y desde ahí mergear la otra rama:

git checkout main
git merge feature

Si los cambios no se superponen, Git hace el merge automáticamente. Para confirmar que una rama ya fue integrada a la actual, podés usar:

git branch --merged

Esto lista las ramas cuyos commits ya forman parte de la rama en la que estás parado.
