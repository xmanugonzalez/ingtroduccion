Lección 3: git log y el historial de commits

Cada commit que hacés queda guardado en el historial del repositorio, con un identificador único (hash), un autor, una fecha y un mensaje. Para ver ese historial:

git log

La versión completa de git log muestra mucho detalle. Para una vista más compacta, de una línea por commit, se usa:

git log --oneline

Esto es muy útil para tener una visión rápida de la evolución del proyecto, y para identificar un commit puntual al que después querramos volver o comparar.
