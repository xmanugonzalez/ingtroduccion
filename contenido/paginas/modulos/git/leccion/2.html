Lección 2: git add, git status y git commit

Git separa el proceso de guardar cambios en dos pasos: primero elegís qué cambios querés guardar (el área de stage), y después los confirmás en un commit, que es una "foto" permanente del proyecto en ese momento.

Para agregar un archivo al stage:

git add nombre_archivo

Para ver qué está en stage, qué está modificado y qué archivos todavía no tienen seguimiento (untracked):

git status

Para confirmar los cambios que están en stage y crear un commit con un mensaje descriptivo:

git commit -m "mensaje descriptivo"

Un buen hábito es escribir mensajes de commit cortos pero claros, que expliquen qué cambió y por qué.
