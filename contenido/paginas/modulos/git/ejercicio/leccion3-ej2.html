Un historial con más de un commit

El repositorio tiene un commit inicial. Creá un segundo commit (puede ser vacío, con --allow-empty) para que el historial tenga más de una entrada.

Escribí uno o más comandos git, uno por línea. Ejemplo: git commit --allow-empty -m "segundo commit"
La salida de tus comandos va a aparecer acá.
