Lección 4: Bucles: for y while

Los bucles repiten un bloque de código mientras se cumpla una condición.

for

Ideal cuando sabemos cuántas veces queremos repetir algo.

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
cout << endl; // imprime: 1 2 3 4 5

El for tiene tres partes separadas por ;: inicialización (int i = 1), condición (i <= 5) e incremento (i++).

while

Ideal cuando no sabemos de antemano cuántas repeticiones van a hacer falta.

int n;
cin >> n;
while (n > 0) {
    cout << n << " ";
    n--;
}
cout << endl;

do-while

Como while, pero garantiza ejecutar el bloque al menos una vez:

int opcion;
do {
    cout << "Ingresa un numero positivo: ";
    cin >> opcion;
} while (opcion <= 0);
