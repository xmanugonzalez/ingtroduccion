Lección 0: Antes de empezar: ¿qué es programar en C++?

Programar es escribir instrucciones, paso a paso, para que una computadora las ejecute. En C++ esas instrucciones se escriben en un archivo de texto con extensión .cpp (el código fuente), pero la computadora no puede correr ese texto directamente: primero necesita traducirlo a un programa ejecutable.

Compilar y ejecutar

Ese trabajo de traducción lo hace un programa llamado compilador (en este módulo usamos g++). El proceso tiene dos pasos bien diferenciados y es importante distinguirlos porque los errores pueden pasar en cualquiera de los dos:

  1. Compilar: el compilador lee tu .cpp y revisa que esté bien escrito según las reglas de C++ (sintaxis, tipos, etc.). Si encontrás un error acá, el programa ni siquiera llega a generarse: es un error de compilación.
  2. Ejecutar: si compiló sin errores, se genera un programa ejecutable y recién ahí se corre. Los problemas que aparecen en este paso (por ejemplo, un bucle que nunca termina) son distintos de los errores de compilación.
En este módulo no hace falta instalar nada: cuando apretás "Ejecutar" o "Entregar" en un ejercicio, tu código se compila y se ejecuta de verdad en el servidor, y vas a ver la salida real de tu programa. Si hay un error de compilación, te va a mostrar en qué línea está y una explicación en español de qué suele significar ese error.

Estructura mínima de un programa

#include <iostream>
using namespace std;

int main() {
    cout << "Hola, mundo!" << endl;
    return 0;
}

Todo programa en C++ necesita una función main: es el punto por donde arranca la ejecución. Las líneas dentro de las llaves { } se ejecutan una por una, de arriba hacia abajo.

Cosas que rompen la compilación (para reconocerlas)

  • Olvidarte un punto y coma ; al final de una instrucción.
  • Dejar una llave { sin su } correspondiente (o al revés).
  • Usar una variable que nunca declaraste, o escribir mal su nombre.
  • Usar algo como cout o string sin haber puesto el #include que corresponde arriba del todo.

No hace falta memorizar esta lista: cuando te pase alguno de estos errores, el módulo te lo va a señalar con la línea exacta y una pista de cómo solucionarlo.

Comentarios

Podés escribir notas dentro del código que el compilador ignora por completo, para explicar qué hace una parte o dejarte recordatorios:

// Esto es un comentario de una sola linea

/* Esto es un comentario
   de varias lineas */

Un vistazo al editor de código

En cada ejercicio vas a tener una caja de texto para escribir tu código, un botón "Ejecutar" para probarlo cuantas veces quieras, y un botón "Entregar tarea" (si venís de una asignación del central). Al escribir, la tecla Tab inserta una sangría (espacios) en vez de sacarte del cuadro de texto, igual que en un editor de código real.
