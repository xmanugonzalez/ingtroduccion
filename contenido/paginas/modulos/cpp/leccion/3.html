Lección 3: Condicionales: if / else

Los condicionales permiten ejecutar distinto código según si una expresión es verdadera o falsa.

int n = 7;
if (n % 2 == 0) {
    cout << n << " es par" << endl;
} else {
    cout << n << " es impar" << endl;
}

Operadores de comparación

OperadorSignificado
==igual a
!=distinto de
>, <mayor/menor que
>=, <=mayor/menor o igual

Encadenando condiciones

if (a > b) {
    cout << "a es mayor" << endl;
} else if (a < b) {
    cout << "b es mayor" << endl;
} else {
    cout << "son iguales" << endl;
}

También existen los operadores lógicos && (Y), || (O) y ! (NO), útiles para combinar condiciones: if (edad >= 18 && tiene_dni) { ... }.
