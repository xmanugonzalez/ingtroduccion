Lección 1: Variables y tipos de datos

C++ es un lenguaje compilado y de tipado estático: cada variable tiene un tipo fijo que se declara antes de usarla, y el código fuente (.cpp) se traduce a un ejecutable con un compilador (el más común en Windows es g++, parte de MinGW-w64) antes de poder correrlo.

Estructura mínima de un programa

#include <iostream>
using namespace std;

int main() {
    cout << "Hola, mundo!" << endl;
    return 0;
}
  • #include <iostream>: importa la librería de entrada/salida estándar.
  • using namespace std;: evita tener que escribir std::cout cada vez.
  • int main() { ... }: todo programa en C++ arranca ejecutando la función main.
  • return 0;: indica que el programa terminó sin errores.

Tipos de datos básicos

TipoUsoEjemplo
intnúmeros enterosint edad = 20;
doublenúmeros con decimalesdouble precio = 19.99;
charun solo carácterchar inicial = 'A';

Declarar e imprimir

int edad = 20;
double altura = 1.75;
cout << "Edad: " << edad << ", altura: " << altura << endl;
Cómo se corrige tu código acá: cuando apretás "Ejecutar" o "Entregar", tu código se compila con g++ y, si compila bien, se ejecuta de verdad — vas a ver la salida real de tu programa (lo que imprime por cout) en la consola de la página. Si tenés un error de sintaxis, te va a mostrar la línea y el mensaje del compilador; si tu programa se queda pegado en un bucle infinito, se corta con un aviso.
