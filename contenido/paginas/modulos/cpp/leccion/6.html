Lección 6: Arrays y vectores básicos

Un array es una colección de tamaño fijo de elementos del mismo tipo.

int numeros[5] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++) {
    cout << numeros[i] << " ";
}
cout << endl;

Los índices arrancan en 0: numeros[0] es el primer elemento.

vector (tamaño dinámico)

Requiere #include <vector>. A diferencia del array, un vector puede crecer y achicarse en tiempo de ejecución.

#include <vector>
using namespace std;

vector<int> lista;
lista.push_back(1);
lista.push_back(2);
lista.push_back(3);

for (int i = 0; i < lista.size(); i++) {
    cout << lista[i] << " ";
}
cout << endl;

// forma moderna de recorrer (range-based for):
for (int x : lista) {
    cout << x << " ";
}

lista.size() devuelve la cantidad de elementos actuales, lista.push_back(valor) agrega un elemento al final.
