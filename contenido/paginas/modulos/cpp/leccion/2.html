Lección 2: Entrada y salida con cin y cout

cout (console output) imprime en pantalla usando el operador <<. cin (console input) lee lo que escribe el usuario usando el operador >>. Ambos viven en <iostream>.

Salida

cout << "Resultado: " << 42 << endl;

Entrada

int edad;
cout << "Ingresa tu edad: ";
cin >> edad;
cout << "Tenes " << edad << " anios" << endl;

cin >> lee hasta el primer espacio en blanco. Para leer una línea completa con espacios (por ejemplo, un nombre compuesto) se usa getline(cin, variable_string).

string nombre;
cout << "Como te llamas? ";
getline(cin, nombre);
cout << "Hola, " << nombre << "!" << endl;

Se pueden encadenar varias lecturas: cin >> a >> b; lee dos valores separados por espacio o salto de línea.
