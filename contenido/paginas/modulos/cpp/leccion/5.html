Lección 5: Funciones

Una función agrupa código reutilizable bajo un nombre. Se define con un tipo de retorno, un nombre y parámetros entre paréntesis.

int sumar(int a, int b) {
    return a + b;
}

int main() {
    int resultado = sumar(3, 4);
    cout << resultado << endl; // 7
    return 0;
}

Si una función no devuelve nada, su tipo de retorno es void:

void saludar(string nombre) {
    cout << "Hola, " << nombre << "!" << endl;
}

Las funciones se pueden declarar antes de main (como en los ejemplos) o declararse arriba (prototipo) y definirse después. Usar funciones evita repetir código y ayuda a organizar el programa en piezas más pequeñas y entendibles.

Recursividad (opcional)

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
