Estructura de un Dockerfile

Un Dockerfile es un archivo de texto plano con una lista de instrucciones, una por línea, que Docker usa para construir una imagen paso a paso. Cada instrucción genera una "capa" (layer) en la imagen final.

Reglas básicas de estructura

  • Las líneas vacías se ignoran.
  • Las líneas que empiezan con # son comentarios y se ignoran.
  • Toda línea de instrucción real debe empezar con una palabra clave en mayúsculas seguida de argumentos, por ejemplo: RUN apt-get update.
  • La primera instrucción no-comentario del archivo debe ser siempre FROM: define la imagen base sobre la que se construye todo lo demás. Sin FROM, Docker no sabe desde dónde partir.

Instrucciones válidas que vamos a usar

FROM, RUN, COPY, ADD, WORKDIR, CMD, ENTRYPOINT, EXPOSE, ENV, ARG, LABEL, VOLUME, USER

Ejemplo comentado

# Imagen base con Python 3.11
FROM python:3.11

# Directorio de trabajo dentro del contenedor
WORKDIR /app

# Copiamos el código al contenedor
COPY . /app

# Comando por defecto al iniciar el contenedor
CMD ["python", "app.py"]
