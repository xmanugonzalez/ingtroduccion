Comandos básicos de la CLI de Docker

Además de escribir Dockerfiles, hay que saber manejar imágenes y contenedores desde la línea de comandos.

docker build

Construye una imagen a partir de un Dockerfile.

docker build -t nombre-imagen .

-t le pone nombre (tag) a la imagen; . es el contexto de build (la carpeta donde Docker busca el Dockerfile y los archivos a copiar).

docker run

Crea y arranca un contenedor a partir de una imagen.

docker run -p 5000:5000 nombre-imagen

-p host:contenedor publica un puerto del contenedor hacia el host. También son comunes -d (modo background/"detached") y --name (nombrar el contenedor).

docker ps

Lista los contenedores en ejecución. Con -a muestra también los detenidos.

docker ps
docker ps -a

docker images

Lista las imágenes descargadas/construidas localmente.

docker images

Otros comandos frecuentes

  • docker stop <id|nombre>: detiene un contenedor.
  • docker rm <id|nombre>: elimina un contenedor detenido.
  • docker rmi <imagen>: elimina una imagen.
  • docker logs <id|nombre>: muestra la salida de un contenedor.
