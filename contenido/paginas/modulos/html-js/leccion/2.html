Lección 2: Elementos y atributos

Los atributos agregan información extra a una etiqueta, dentro de la etiqueta de apertura: <a href="https://ejemplo.com">link</a>.

  • <p> párrafo de texto.
  • <ul>/<ol> con <li> para listas.
  • <a href="..."> enlaces.
  • <img src="..." alt="..."> imágenes (etiqueta vacía).
  • id="..." identifica un único elemento (útil para JS/CSS).
  • class="..." agrupa elementos para darles el mismo estilo.

Ejemplo:

<ul id="lista">
  <li class="item">Uno</li>
  <li class="item">Dos</li>
</ul>
