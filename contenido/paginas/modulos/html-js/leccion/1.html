Lección 1: Estructura básica de HTML

Todo documento HTML tiene un esqueleto mínimo que el navegador espera para interpretar la página correctamente:

<!DOCTYPE html>
<html>
  <head>
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola mundo</h1>
  </body>
</html>
  • <!DOCTYPE html> le dice al navegador que es HTML5.
  • <html> envuelve todo el documento.
  • <head> contiene metadatos (título, estilos, etc.), no se ve en pantalla.
  • <body> contiene el contenido visible de la página.

Cada etiqueta que se abre (<tag>) debe cerrarse (</tag>), salvo las etiquetas "vacías" como <br> o <img>.

Cuando apretás Ejecutar, vas a ver el resultado en la vista previa y, si algo está mal escrito, un mensaje te va a indicar qué etiqueta o símbolo falta y en qué línea aproximada está el problema.
