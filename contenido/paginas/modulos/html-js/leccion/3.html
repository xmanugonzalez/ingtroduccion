Lección 3: CSS básico: inline e interno

Hay tres formas de aplicar CSS; acá vemos dos:

  1. Inline: con el atributo style directo en la etiqueta: <p style="color: red;">texto</p>.
  2. Interno: con una etiqueta <style> dentro del <head>, usando selectores:
<head>
  <style>
    body { font-family: sans-serif; }
    .destacado { color: orange; font-weight: bold; }
    #titulo { text-align: center; }
  </style>
</head>

Los selectores más comunes: por etiqueta (p), por clase (.destacado) y por id (#titulo).
