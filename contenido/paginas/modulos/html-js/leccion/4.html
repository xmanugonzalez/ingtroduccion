Lección 4: JavaScript básico: variables y funciones

El código JavaScript va dentro de una etiqueta <script>, normalmente al final del <body>.

<script>
  let nombre = "Ana";
  const PI = 3.14;

  function saludar(persona) {
    return "Hola, " + persona;
  }

  console.log(saludar(nombre));
</script>
  • let declara una variable que puede cambiar.
  • const declara una variable que no se puede reasignar.
  • function nombre(parametros) { ... } declara una función.
  • console.log(...) imprime en la consola del navegador.
