# ing-troduccion

Plataforma educativa de cursos breves para la Universidad UNIDA, orientada a dar los primeros pasos en la Ingeniería en Informática mediante explicaciones sencillas y ejercicios de programación.

## Cursos

El contenido se organiza en seis módulos independientes:

- **C++:** variables, tipos de datos, entrada y salida, condicionales, bucles, funciones y estructuras de datos básicas.
- **HTML + JavaScript:** estructura de páginas web, elementos, atributos, estilos, funciones, eventos y manipulación del DOM.
- **SQL Server:** creación de tablas, carga y consulta de datos, filtros, relaciones y agrupaciones.
- **Python:** variables, operadores, entrada y salida, condicionales, bucles, funciones y listas.
- **Docker:** contenedores, imágenes, Dockerfiles y comandos básicos.
- **Git:** repositorios, preparación de cambios, commits, historial, ramas y merge.

## Aprendizaje práctico

Cada módulo reúne lecciones breves, ejemplos y ejercicios con un editor de código. La propuesta combina la práctica con consolas de resultados y corrección automática para ayudar a comprender los errores. En HTML y JavaScript, una vista previa permite observar el resultado de la página dentro de un iframe.

## Alumnos y docentes

El sistema está pensado para que los alumnos practiquen, consulten su progreso y entreguen tareas, y para que los docentes organicen clases, asignen ejercicios y revisen y califiquen las entregas.
